# 🚚 SwiftRoute Logistics & Operations Analytics Dashboard

## 📌 Project Overview
The **SwiftRoute Logistics Dashboard** is an end-to-end Power BI reporting solution designed to monitor supply chain efficiency, track delivery performance, evaluate driver reliability, and manage hub and vehicle capacity.

The interactive multi-page dashboard provides real-time insights into fleet utilization, fulfillment rates, and operational bottlenecks.

---

## 📊 Multi-Page Navigation Breakdown
1. **Executive Overview Dashboard:** Core KPIs including total orders, MoM growth, On-Time Delivery Rate (%), Customer Satisfaction (CSAT %), Average Delivery Time, and overall fleet utilization.
2. **Drivers Overview:** Deep dive into individual driver metrics, delay analysis, experience tracking, and monthly performance trends.
3. **Hubs Overview:** Capacity vs. order processing load across key logistics hubs, hub performance rankings, and daily order distributions.
4. **Vehicles Overview:** Fleet health management, active vs. maintenance status breakdown, and vehicle model usage statistics.

---

## 🔑 Key Metrics Analyzed
- **Total Orders Processed:** 1,130 (MoM Tracking)
- **On-Time Delivery Rate:** 81.63% (MoM: +3.04%)
- **Customer Satisfaction Score (CSAT):** 86.46%
- **Average Delivery Time:** 35.94 mins
- **Active Vehicles Fleet Ratio:** 73.33% Active | 26.67% Under Maintenance
- **Infrastructure:** 6 Logistics Hubs | 55 Drivers | 45 Vehicles
